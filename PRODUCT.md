# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User specified Babylon.js Editor v5 native Vanilla, strict TypeScript, pnpm, Vitest and Playwright. Vite is the native build tool.

## Users and purpose
Developers evaluating a standalone browser client foundation for later Interlude integration. The current deliverable is a working synthetic scene with a replaceable world adapter.

## Capabilities and constraints
Exactly six initial characters, animation, interpolation, camera, targeting and lifecycle demonstrations. Static environment stays editable in Babylon.js Editor. No proprietary game assets, networking, progression or deployment. Source reuse requires a redistribution grant.

## Interface commitment
The user selected a game-like scene with compact controls. Diagnostics and demonstration controls remain visible. All entity data is synthetic.

Mobile first. The user supplied a classic Lineage II HUD reference: dark translucent panels, bronze borders, top-left health and bottom action controls. Translate that reference into original touch-friendly interface elements; no proprietary screenshot pixels or game assets ship.
