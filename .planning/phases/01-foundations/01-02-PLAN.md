Functions: `lower_process_priority()` (on win32 call `SetPriorityClass(GetCurrentProcess(), 0x00004000)` through ctypes, BelowNormal), `reject_reparse_ancestors(root)` (root and every parent must not carry `stat.FILE_ATTRIBUTE_REPARSE_POINT`), `walk_regular_files(root)` (iterative `os.scandir`, `entry.stat(follow_symlinks=False)`; any reparse point or symlink inside the tree raises ValueError naming the path), `hash_tree(root)` returning `{"schemaVersion": 1, "root": <root as given>, "host": socket.gethostname().upper(), "pythonVersion": platform.python_version(), "files": [...], "unreadable": [...]}` where each file row is `{"path": <POSIX relative path, original case>, "bytes": int, "sha256": lowercase hex via hashlib.file_digest, "modifiedNanoseconds": st_mtime_ns}` and an OSError while opening or reading a file adds `{"path", "reason": <exception class and errno>}` to `unreadable` instead of aborting; both lists sorted by `(path.casefold(), path)`. `canonical_json_bytes(value)` serialises with `ensure_ascii=False, sort_keys=True, separators=(",", ":"), allow_nan=False` encoded UTF-8. Entry: the root comes from `sys.argv[1]`; it must exist, be a directory and contain at least one regular file, else exit with a message naming the root; output goes to `sys.stdout.buffer.write`. It never opens a file for writing.

Create `scripts/build_reference_client_lock.py`: `classify_reference_client_trees(importa_manifest, e_manifest, hashing_script_sha256)` joins rows by casefolded path. Classes: `equal` (same bytes and sha256), `differing`, `importa-only`, `e-only`, `volatile-config` (file name casefold matches `*.ini`, `*.log`, `*.bak`, `*.bak-*`, regardless of content, so conversion never reads it), `unreadable` (listed unreadable on either side). Output object: `schemaVersion: 1`, `referenceHost: "IMPORTA-PC"`, `referenceRoot: "C:/Lineage2-client"`, `conversionHost: "DATABASE-PC"`, `conversionRoot: "E:/Lineage2-client"`, `hashingScriptSha256`, `hosts` (per side: host, root, pythonVersion, fileCount, totalBytes, unreadableCount), `classCounts`, `volatileConfigPatterns`, `fileFields: ["class", "importaBytes", "importaSha256", "eBytes", "eSha256", "eModifiedNanoseconds"]`, `files` (object keyed by the IMPORTA spelling of the path, or the E spelling when e-only, value a six-element array in fileFields order with null where a side has no value), `caseDifferences` (sorted pairs `[importaPath, ePath]` when spellings differ), `unreadable` (sorted rows with side and reason). `write_reference_client_lock(lock, output_path)` writes `json.dumps(lock, ensure_ascii=False, sort_keys=True, indent=1)` plus a final newline. CLI: `--importa-manifest`, `--e-manifest`, `--output` (default `recipes/reference-client-tree.lock.json`); it computes `hashingScriptSha256` from the tracked `scripts/hash_reference_client_tree.py` bytes and refuses a manifest whose schemaVersion is not 1 or whose rows are not sorted.

When the resolved root casefolds equal to the conversion root: the lock must exist (else ReferenceClientLockError "reference client lock missing: recipes/reference-client-tree.lock.json; the integration thread runs the hash lock before any E: read"), parse with schemaVersion 1, and `system/Engine.dll` must pass the same per-file check. `require_equal_file`: reject absolute paths, `..` segments and backslashes; for a lock-requiring root the casefolded path must exist in `files` with class `equal`; if current size and st_mtime_ns equal the lock's eBytes and eModifiedNanoseconds accept, otherwise re-hash and accept only when the digest equals eSha256, else raise ReferenceClientLockError "reference client lock is stale for <path>; re-lock ordered". For any other root (the IMPORTA-PC snapshot, temporary test trees) only path confinement applies. Cache accesses per (root, lock path).
