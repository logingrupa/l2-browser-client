Per CONTEXT decision A. Create `src/assets/native/readNativeCatalog.ts` exporting `NativeStoreNotStagedError extends Error`, interface `NativeCatalog` (readonly `schemaVersion: 1`, `models`, `textures`, `sections`, `movers`, `npcProfiles`, `playerProfiles`, `animationAudio`, `combatAudio`, `worldAudio`, `effectComponents`, each `readonly unknown[]`, absent keys as empty arrays), and `readNativeCatalog(signal: AbortSignal, fetchResource: typeof fetch = fetch): Promise<NativeCatalog>`. It fetches `nativeResourceUrl("/l2/catalog.json")` once per signal (a module `WeakMap<AbortSignal, Promise<NativeCatalog>>`; a rejected promise is evicted so a later call with the same signal retries the fetch once the caller asks again). HTTP 404, or a body that starts with an HTML doctype or html tag, throws `NativeStoreNotStagedError` with the message "Native asset store not staged: /l2/catalog.json is missing. Stage it from the main checkout."; any other non-ok status throws "Native asset catalog returned HTTP <status>."; the parsed body must be an object with schemaVersion 1 and an array `models`, and every other listed key, when present, must be an array, else "Native asset catalog is invalid.".

Create `src/assets/native/nativeCatalogIndex.ts` exporting key builders `npcCatalogKey(npcId)`, `itemCatalogKey(itemId)`, `skillCatalogKey(skillId, level)` (each requires `Number.isSafeInteger` and value at least 0, level at least 1, else throws RangeError), `windowCatalogKey(name)` (name matches `^[A-Za-z][A-Za-z0-9_]{0,63}$`), `tileCatalogKey(tile)` (matches `^\d{2}_\d{2}$`); type `NativeCatalogLookup = { status: "converted"; key; record } | { status: "not-in-catalog"; key; reason }` with record types `NativeNpcCatalogRecord { npcId, profileId, modelCatalogId }`, `NativeItemCatalogRecord { itemId, slot: "upper", catalogIds, playerProfileIds }`, `NativeSkillCatalogRecord { skillId, level, effectComponentId }`, `NativeTileCatalogRecord { tile, sectionId }`; interface `NativeCatalogIndex { lookup(key): NativeCatalogLookup; keys(prefix): readonly string[] }`; and `buildNativeCatalogIndex(catalog, signal): Promise<NativeCatalogIndex>`. Sources: npc from `loadNativeNpcProfiles(catalog.npcProfiles, signal)` joined to the one model record whose `source.object` equals the profile `mesh` (profile without a model: not in catalog, reason "NPC profile staged but mesh <mesh> has no converted model"); item from `loadNativePlayerProfiles(catalog.playerProfiles, signal)` upperItems whose catalogId is a model record id; skill from effect component ids matching `^interlude:skill:(\d+):level:(\d+):`; tile from section ids matching `^map-(\d{2})-(\d{2})-section$` mapped to `XX_YY`; window keys are always not in catalog with reason "interface windows are not converted yet (UI-01)". Duplicate model ids, duplicate section ids or two records producing one key throw "Native catalog has duplicate entries for <key>.". Unknown keys return not in catalog with reason "not in catalog".

Rewrite `src/assets/native/loadNativeCatalog.ts` so its private catalog read becomes a call to `readNativeCatalog(signal)` (delete the local fetch and envelope check); keep exported function names and behaviour. Remove all comments in every touched file.
