Sizes: absolute width and height from the node; relative sizes `Math.trunc(rate * parentSize + offset)` for width and height, height labelled unverified because the document notes extra native handling. Position: start from the parent's left and top, then apply the documented update `left += offsetX - selfPointX + targetPointX` (same for top), each point truncated toward zero with `Math.trunc` in the documented order; an empty target is the parent (the screen for a root); a named target is the one node of the same window with that name. Gaps: `anchor-unresolved:zero-anchor-enum`, `anchor-unresolved:no-position` (placed at the parent origin), `anchor-unresolved:target-missing`, `anchor-unresolved:target-ambiguous`, `anchor-unresolved:cycle`.
