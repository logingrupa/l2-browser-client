<threat_model>
## Trust boundaries

| Boundary | Description |
|----------|-------------|
| DATABASE-PC to IMPORTA-PC over ssh | remote commands and data cross a machine boundary into the owner's interactive session |
| IMPORTA receipts and PNGs back to the repository | remote files are untrusted until re-hashed |
| decoded npc names to remote input | names from a decoded table reach a remote program |

## STRIDE threat register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-13 | Tampering | remote PowerShell programs | high | mitigate | data travels as base64 JSON through `-EncodedCommand`; programs never interpolate keys, names or paths; tests assert the encoded form |
| T-03-14 | Spoofing | native halves | high | mitigate | PNG SHA-256 computed on IMPORTA is re-checked after scp; Engine.dll and controller hashes tie the receipt to the lock; the writer refuses a foreign lock reference |
| T-03-15 | Tampering | remote write scope | high | mitigate | every remote path is confined to `debug-control/captures/<batch>/`; nothing is written in `C:/Lineage2-client`; refusal tests run before any remote call |
| T-03-16 | Denial of service | the owner's client and bot | high | mitigate | the preflight refuses a foreign `l2.exe`, the bot and an inactive session; Phase 3 never runs the driver against IMPORTA |
| T-03-17 | Repudiation | scheduled task lifecycle | medium | mitigate | the task is unregistered in `finally` and proven gone; l2.ini before and after are compared and printed |
| T-03-SC | Tampering | npm/pip installs | low | accept | no package is installed in this plan |
</threat_model>
