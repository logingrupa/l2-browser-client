## Trust boundaries

| Boundary | Description |
|----------|-------------|
| receipts to ingest | browser-written JSON and images are untrusted until re-hashed and validated |
| decoded tables to native selection | npc names come from a decoded file and later reach a remote command line in the driver |
| reviewer CLI input | verdict arguments are operator input |

## STRIDE threat register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-08 | Spoofing | `ingest-sandbox-halves` | high | mitigate | the PNG is re-hashed and the key digest recomputed on the current union; mismatches are refused as stale or forged captures |
| T-03-09 | Tampering | `native_selection_for_key` | medium | mitigate | names and mesh texts are read from decoded tables and profiles and stored as data; the driver (03-06) passes them as base64 JSON, never interpolated |
| T-03-10 | Elevation of privilege | `judge` | medium | mitigate | the 03-01 validator refuses a reviewer equal to a capturer, a verdict without both halves and an agent audio verdict; tests prove the file stays byte-identical on refusal |
| T-03-SC | Tampering | npm/pip installs | low | accept | no package is installed in this plan |
