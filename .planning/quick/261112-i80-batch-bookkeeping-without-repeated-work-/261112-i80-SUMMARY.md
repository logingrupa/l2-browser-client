### Reach of the actor-sound catalog repair

A slice repairs every sealed bundle it walks, from the receipt the skip already read. After a stopped slice that is every bundle it sealed, when the keys and the fingerprints are unchanged: those bundles come before the first unsealed key, and the limit breaks the loop only after a conversion. When an earlier key is unsealed by then, the limit can break the loop before one of them; the slice that walks that bundle repairs it. Keys past the limit break are not walked.

Tests in `test_actor_sound_slice_bookkeeping.py`, class `ActorSoundSealedBundleRepairTests` unless named:

| Case | Test |
|---|---|
| Missing record added | `test_the_missing_record_of_a_sealed_bundle_is_added_again` |
| Record that pins another manifest replaced | `test_a_record_that_pins_another_manifest_is_replaced_by_the_record_of_the_sealed_receipt` |
| Record of a bundle sealed without a manifest removed | `test_the_record_of_a_bundle_sealed_without_a_manifest_is_removed` |
| Both stale records at once | `test_a_stale_record_and_a_record_without_a_manifest_are_repaired_in_one_slice` |
| Deleted gap-row file restored | `test_the_deleted_gap_row_file_gets_the_rows_of_the_sealed_bundles_again` |
| Steady state writes no file | `ActorSoundSliceWriteCountTests.test_a_slice_over_an_unchanged_store_writes_no_file` |
| Stopped slice leaves the first bundle synchronized | `ActorSoundSliceWriteCountTests.test_a_slice_stopped_by_its_preflight_leaves_the_bundles_converted_so_far_synchronized` |

Each repair test also runs one more slice and checks it as a steady state: no outcome, no preflight, no `write_store` and no `replace_file` call, and the bytes and `st_mtime_ns` of every file under the temporary project root unchanged.
