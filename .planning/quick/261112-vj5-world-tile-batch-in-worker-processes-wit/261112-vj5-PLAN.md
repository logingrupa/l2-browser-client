## Decisions the orchestrator must revisit

- **D-02, phase B, "every registered step except manifest".** It cannot hold as written: the list cannot include the raw step. A second raw call on a unit that is not sealed after phase A runs `ledger.begin`, which removes and rewrites the raw unit folder (`scripts/native_store/unit_ledger.py:289`), while the terrain step of another worker reads that folder without a lock (`scripts/world/terrain_seam_strip.py:97`, `scripts/world/terrain_seam_facts.py:146`). The owner's terrain result would then depend on timing. This plan runs the raw step in phase A only, as the word "once" of phase A says. Phase B runs every registered step except raw and manifest and starts from the phase A raw result of its tile: a failed raw row turns the tile's other steps into upstream-failed rows, as today. The rows, the raw call count and the raw preflight count of a tile equal today's. Suggested wording for the context file: "every registered step except raw and manifest, starting from the phase A raw result of the tile".
- **D-04, third place, "around the `class:Engine.Mover` unit seal in `mover_step.py`".** The seal alone is not enough as written. `sealed_mover_unit_config` (`scripts/world/mover_step.py:100`) reads the same unit folder through the pinned `sealed_mover_class_receipt_sha256` without a lock, and the coordinator reaches it in phase C (`run_tile_manifest_step` line 368, through `sealed_movers`) while a worker of a later tile makes the first class seal. `UnitLedger.seal` creates `complete.json` before it writes it (`scripts/native_store/unit_ledger.py:65-67`, `334-336`), and a reader that meets the empty file raises `UnitLedgerError` (`72-74`): a failed manifest row that one worker never produces. This plan takes the lock of the class unit key around both calls of `mover_step.py` into the pinned module (task 1, fact 16). Suggested wording for the context file: "around every call of `mover_step.py` into `mover_class_defaults.py` (the read or seal in `run_mover_step` and the sealed-receipt read in `sealed_mover_unit_config`), keyed by that unit".
