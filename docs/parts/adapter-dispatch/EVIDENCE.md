# Server adapter: event dispatch evidence

Part `adapter-dispatch`, lane `integration`. What passes now, what is open, and where the proof lives. Keep this file under about 30 KB.

## Passes now

- The sandbox command contract has 12 WorldCommand members, adding `spawn-character` (chargrp template index) and `play-clip` (entity id and exact clip name) in plan 02-10 and dropping the courtyard-only `teleport-local` and `spawn` with `MockWorldAdapter` (DEC-OWN-11). `NativeSliceAdapter`, the only adapter, dispatches exhaustively with a `never` default. Evidence: `tests/unit/gameWorldAdapterContract.test.ts` and `tests/unit/sandboxCommands.test.ts`.
- Shared Babylon-free modules (plan 02-56, DEC-OWN-12). `src/shared/` holds the typed payload reader (`typedPayload.ts`), vector, affine matrix and plane math (`math/`), the rotator rules (`math/rotator.ts`), seeded domain-tagged random streams (`random.ts`), the presentation clock (`presentationClock.ts`) and the fixed-step accumulator (`fixedStep.ts`). `src/world/sourceFrame.ts` is the one source-to-scene transform: `world = (x, z, y) * 0.01`, `source = (X, Z, Y) * 100`, rotations conjugated by the same axis swap, headings at 65536 units per turn with 0 along source +X and 16384 along source +Y, as Babylon `rotation.y` with `useRightHandedSystem`. The debug position readout and the diagnostics `sourceSpawn` go through it. Evidence: `tests/unit/typedPayload.test.ts`, `sourceFrame.test.ts`, `nativeSliceDebugPosition.test.ts`, `sharedMath.test.ts`, `sharedRandom.test.ts`, `presentationClock.test.ts`, `goldenTrace.test.ts` and `importBoundaries.shared.test.ts`.
- Typed payload container: `asset.json` `{units: "source", axes: "ue2-z-up", sourceSha256, converterVersion, arrays: [{name, type, count, byteOffset, byteLength}]}` plus one little-endian payload. Types are `float32`, `int32`, `uint32` and `uint8`. Names follow `<GROUP>.<field>` with a four-letter upper-case group. Arrays sit in list order, the first at byte 0 and each next one at the following 4-byte boundary; `byteLength` is `count` times the element size, the gap up to the boundary is zero bytes, and the payload ends at the last boundary. The reader refuses each fault with `TypedPayloadError` naming the array and returns views over the given bytes without copying.
- Golden payload: `tests/fixtures/typed-payload/asset.json` and `payload.bin` (synthetic values only, D3), written by `writeTypedPayloadFixture` in `tests/support/typedPayloadFixture.ts` from `goldenTypedPayloadArrays`: `TEST.positions` float32 `[1.5, -2.25, 0.1, 3.4028234663852886e38, -0]`, `TEST.indices` int32 `[-1, 0, 2147483647, -2147483648]`, `TEST.flags` uint32 `[0, 1, 4294967295]`, `TEST.bytes` uint8 `[1, 2, 255]` with one zero padding byte, 52 bytes in all. `.gitattributes` keeps both files byte-exact. 02-30's Python writer compares its bytes with this golden.
- Constants rows: every reference rule in `rotator.ts` and `random.ts` is `{id, value, provenance, status, interludeEvidence, runtimeDefault}` with status `unconfirmed`: `rotator.units-per-turn`, `fx.sine-table`, `fx.sine-table-half-turn`, the per-use rules `fx.revolution-angle` (table), `camera.direction` (table), `uv.rotator-conversion` (exact) and `placement.rotator-conversion` (table), `fx.frange-draw` and `fx.unit-vector-draws`. The largest table-to-exact sine difference over all 65536 inputs is pinned at 0.0002876213937629265 (units 3).
- Golden traces: `tests/support/goldenTrace.ts` writes a trace at a declared seed and step with float32 values and compares float32 arrays by ulp distance (largest distance and first index past a limit). Every lane may use it.
- D7 vendor boundary (plan 02-57, DEC-OWN-12). `tests/unit/importBoundaries.vendor.test.ts` fails when any `src/**` module imports `@recast-navigation/*`, `@babylonjs/materials` or `@babylonjs/node-particle-editor`, statically, by `export from` or by `import()`, except `src/scene/openBabylonInspector.ts`, the lazy inspector entry. It also fails on any use of `ParticleSystem`, `GPUParticleSystem`, `SolidParticleSystem`, `moveWithCollisions` or `checkCollisions`, because no vendor supplies emitter or movement semantics (FX-01, MOVE-01). Synthetic probe sources prove each refusal names the module or line.
- Dependency move: `@recast-navigation/core` and `@recast-navigation/generators` left `dependencies` and stay pinned at 0.43.0 in `devDependencies`, only for the Editor navmesh plugin test (`tests/editor/editorScript.test.ts`). The lockfile moves the two importer entries between sections and adds no package; `pnpm install --offline --frozen-lockfile` accepts it, and `pnpm build` passes. `@babylonjs/materials` and `@babylonjs/node-particle-editor` stay runtime dependencies because the lazy inspector loads them.
- Reference overlap check: `node tools/reference-overlap/referenceOverlap.mjs --area <materials|bsp-visibility|movement|particles|network> [--reference-root <dir>]` is the one clean-room check for every DEC-OWN-12 area. It reads source and reference files as text only (no `import()`, `require`, child process or eval; the test scans the tool for them). Tokens drop comments and import declarations, identifiers and strings become placeholders, and identifiers match under consistent renaming, so renaming every identifier does not hide a run while a changed number does. Every shared run of 12 or more tokens is listed for a reviewer, grouped by source span with every reference match; a run of 20 or more outside the area's constant allowlist exits 1. A missing clone (`reference clone absent: <path>`), a clone off its pinned commit or a reference glob that matches nothing exits 2, never a pass. `tools/reference-overlap/overlapAreas.json` holds the thresholds, the two pinned clones and per area the source globs, the reference globs and the allowlist; the network globs are listed now for Phase 4. A worktree reads the main checkout's clones with `--reference-root C:/laragon/www/l2-browser-client`. Evidence: `tests/unit/referenceOverlap.test.ts` (11, 12, 19 and 20 token cases, renaming, a changed literal, comments, an allowlisted table, absent and wrong-commit clones) over synthetic fixtures in `tests/fixtures/reference-overlap/`.
- Reviewer sign-off rule: a reviewer who did not write the code signs off each reviewer run in the owning part's `EVIDENCE.md`, naming the source span and why it is not copied. Blocking runs are rewritten, or the owner moves a true constant table (opcodes, key bytes, sine tables, enum ordinals, the identity matrix) into the allowlist.
- One class-default reader (plan 02-59, DEC-OWN-12). `scripts/native_assets_lib/class_defaults.py` `read_class_defaults_with_provenance(class_name, fields, work_root, class_scripts)` walks the class chain from the export table, decompiles each class once through the pinned UELib (`ReferenceClientClassScripts` calls the data-ui `read_class_defaults`, unchanged) and caches it under `<work_root>/class-defaults/<Class>.json`, reused while the package SHA-256 and UELib pin stay the same. Provenance vocabulary `CLASS_DEFAULT_PROVENANCES = ("authored", "class-default", "ue-zero")`: the queried class's own `defaultproperties` are `authored`, an ancestor's are `class-default` with the setting class, a declared field nobody sets is `ue-zero` with value null, and an undeclared field is refused. Struct and static-array defaults inherit member by member; a redeclared field hides the ancestor's (Interlude `Engine.Shader` redeclares `AlphaRef`). `read_class_field_declarations` lists every visible field with its declared type and enum members. Real-client checks: `Engine.StaticMeshActor.bBlockPlayers` is `true`, authored by `Engine.StaticMeshActor`; `Engine.FinalBlend.FrameBufferBlending` member 8 is `FB_Add`.
- Material graph and typed program (plan 02-59, MAT-01 converter half, CONV-02). `material_graph.py` `read_material_graph(package, root_export)` walks one root inside its package for any owner, keeping every node's property tags as decoded, its export span and native tail by hash, and every reference (imports recorded, not followed). `AnimNext` loops are kept; any other cycle and a forged reference are refused; 128 nodes at most. `material_program.py` `derive_material_program(graph, class_defaults)` writes `{schemaVersion 1, kind "ue2-material-program", graphSha256, root, nodes, gapReasons}`; each reviewed node lists every field below `Core.Object` with `provenance` `authored`, `class-default` or `ue-zero`, enums as `{ordinal, name}` from the decompile, references as node ids, structs as raw bytes. Nothing is flattened or evaluated. `material_resources.py` `write_native_material_resources` writes `/l2/native-materials/<sha>/graph.json` and `program.json` through `require_converter_output`. Real check: all 46 Shader, Combiner and FinalBlend roots of `textures/FX_E_T.utx` convert, with only `material-class-unported:Engine.TexOscillatorTriggered` as a gap.
