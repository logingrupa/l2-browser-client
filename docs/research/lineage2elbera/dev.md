Its regression check requires HTTP/1.0, connection closure and specific cache headers (`tools/dev/measure_http.py:257`). `keepalive_server.py` imports `editor/world/server.py` and subclasses its handler; it defaults to loopback port 8084 and backlog 5 (`tools/dev/keepalive_server.py:60`, `tools/dev/keepalive_server.py:114`, `tools/dev/keepalive_server.py:245`). Even `--check` starts a listener and also requires the original server and generated tile fixture (`tools/dev/keepalive_server.py:187`). Neither is standalone against this client.

Its tests combine portable synthetic validation with upstream world-fixture imports (`tools/dev/db_cli.test.cjs:18`, `tools/dev/db_cli.test.cjs:40`). `seed_test_char.py:47` requires aCis XML, decoded item names, MariaDB and, on apply, mysqldump. Character names enter SQL unescaped (`:148`); the purported `.sql` backup contains tabular SELECT output, not restoration SQL (`:192`). Allocation and offline checks can race; restart guidance assumes macOS/Homebrew and Unix process tools (`:229`).

Locally, Vite runs on 5173 (`vite.config.ts:15`), while nginx preview already configures backlog/connection capacity (`scripts/private-preview.mjs:106`). Native loading fetches `/l2` resources (`src/scene/world/loadNativeSection.ts:140`), and `readAssetPackage` verifies hashes (`src/assets/package/readAssetPackage.ts:94`). Existing upstream BSP reuse is pinned in `scripts/vendor/lineage2elbera_bsp/SOURCE.json:3`.

Verdict: reference HTTP measurement methodology; defer keepalive server and character seeding. Adapt `dbArgs` only when a MariaDB integration exists. Smallest useful future proof: parameterize HTTP resource paths and compare byte completeness, protocol and cache behavior on synthetic fixtures, then compare browser Resource Timing under representative concurrency. Serial estimates cannot establish browser throughput, rendered fidelity or runtime parity. Execution was limited to inventory and source reads; no tests, listeners, database access or lifecycle commands ran, and private fixtures/dependencies were not validated.
