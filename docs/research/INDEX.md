## Scales

- Status: current (live input or evidence for a requirement, code, test or current doc), superseded (a later folder, doc or code replaced it), moot (the question no longer matters under a locked decision), orphan (nothing cites it and it has no conclusion).
- Soundness: sound (conclusions backed by evidence inside it), partly-sound (some backed, or partial and failed runs), unsupported (claims or dumps with no evidence or conclusion), contradicted (later evidence or a decision contradicts it).
- Location: in place (`artifacts/native-parity/research/<name>` in the main checkout), archived (moved to `C:\laragon\l2b-research-archive\2026-11-08\<name>`, same name; `MOVED.json` there lists original paths for a restore), tracked (in this repo).

## Archive rule

An entry moved to the archive when it was not current and no tracked code, test, recipe or config read it. Tracked docs may still name an archived entry; look it up here by name. Entries read by tracked code stay in place whatever their rating.
